# iTv pour Windows — app prête à lancer

**Télécharger :** bouton vert **Code** → **Download ZIP**, puis dézippe et lance `iTv/iTv.exe`.

Si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* → *Exécuter quand même*.

Cette branche est générée automatiquement par GitHub Actions à chaque mise à jour.
Le code source est sur la branche `main`.
